One gateway, three flagships — what a correct answer actually costs.

GPT-5.6 Sol, Claude Fable 5 and Kimi K3, run through a single neutral endpoint and graded deterministically. The new OpenAI flagship wins both axes at once — most accurate and cheapest per correct answer. And the twist that matters for your bill: Kimi K3 has the cheapest tokens of the three, yet the priciest per-token model isn't the priciest per answer — because what you pay for is output, and output efficiency, not sticker price, decides cost.

Why the cheapest token isn't the cheapest answer

You pay per token, but you buy correct answers — and a model that thinks out loud burns tokens getting there. Median output per answer:

Kimi has the cheapest tokens ($3/$15 per M vs Sol's $5/$30) but emits 4.3× more output — 82% of it hidden reasoning it still pays for — so it lands pricier per correct answer. Terse beats cheap.

What we caught before trusting these numbers

The first run produced three plausible-but-wrong results. Each was a measurement artifact, not a capability gap — found and fixed before publishing:

  1. Sol coding 71% → 95%. The grader dropped HumanEval's from typing import List, so correct terse code threw NameError.
  2. Fable long-context 0% → 93%. A "retrieve the secret access code" needle prompt tripped Anthropic's content filter; reframing to benign fact-retrieval fixed it. The same filter refuses ~11/60 Hindi medical MCQs — which is most of why Fable's Hindi reads low.
  3. Math looked like 40–60% → ~87%. Reasoning models were hitting a 300-second timeout mid-thought; timeouts were being counted as wrong answers. Raised to 10 minutes — the models tie at 87%, and the few remaining misses are genuine timeouts on the hardest AIME problems.
Method. 5 axes — HumanEval (coding), AIME 2025 (math), Global-MMLU Hindi (Indic), synthetic needle (long-context), IFEval (instruction-following). Every call routed through api.bharatrouter.com with one br- key; provider keys stay in BharatRouter's BYOK vault. Accuracy shown with 95% Wilson confidence intervals; gaps inside the interval are ties. ₹ is computed from realized-route token counts (BYOK bills ₹0 on BR). Prices validated against Anthropic, Moonshot and OpenRouter list rates — identical to the cent. Caching caveat: Fable and Kimi offer 90% prompt-caching discounts on input tokens; we don't cache (each request is independent, applied equally to all), and it wouldn't change the ranking anyway — the cost here is dominated by output, which caching never discounts. 570 graded calls · ~₹3.1k for the final dataset.
